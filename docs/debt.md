# Technical Debt Register

Rules: every deliberate shortcut ships with an entry here (same PR). Each entry: what the shortcut is, what it will break or block, and the observable **trigger** that makes repayment mandatory. Trigger fires → repayment enters the current quarter, funded from the 20% reserve. Re-snoozing a fired trigger happens in writing, in this file. Full protocol: [docs/founder-os/14-tech-debt.md](founder-os/14-tech-debt.md).

| # | Debt | What it breaks / blocks | Trigger for repayment | Status |
|---|---|---|---|---|
| 1 | Direct model imports, no stage interfaces (`backend/pipeline.py` calls Whisper/GoogleTranslator by name) | Every model swap touches pipeline code; sovereignty swaps (Ch. 15) blocked | First model swap attempt — already scheduled by licensing (translation first) | Partially repaid — the Synthesizer stage has a real interface (`backend/stages/synthesizer.py`; Edge-TTS and XTTS adapters, decision record 0001). Transcriber/Translator remain plain functions in `pipeline.py`; their interfaces arrive with their first swap (translation is first in the Ch. 15 order) |
| 2 | Global `progress.json`, no job identity | Two concurrent users corrupt each other's progress; no audit trail | Second concurrent user — i.e. first real customer trial | **Repaid** — `backend/jobs.py`: per-job ids, `progress/{id}.json`, `outputs/{id}.mp4`, `jobs/{id}/` audit dir |
| 3 | `subprocess.Popen` fire-and-forget in `/jobs`, no queue | Lost jobs are undetectable; no retries; no failure states | First lost-job incident or first customer, whichever first | Partially repaid — failure states now visible (`state: error` in per-job progress) and concurrency refused via pid-checked lock (409). Extended: still no queue and no retries; a second submission is refused, not queued. Trigger unchanged |
| 4 | No auth, CORS `*` | Anyone reaching the server can submit jobs and fetch outputs | Any non-demo deployment reachable from the internet | Open |
| 5 | Output always overwrites `outputs/final_dubbed.mp4` | Every job destroys the previous job's result | Same as #2 (first concurrent use) | **Repaid** — outputs are `outputs/{job_id}.mp4`; the rename to `final_dubbed.mp4` is gone |
